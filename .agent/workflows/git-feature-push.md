# Git Feature Push Workflow

Trigger: `"/commit"`, `"prepara commit"`, `"sube los cambios"`

## Pasos

1. **Status check**: `git status` (comprobar archivos modificados)
2. **Diff review**: `git diff` (revisar cambios)
3. **Stage**: `git add <archivos>` (solo archivos relevantes)
4. **Commit**: Seguir formato Conventional Commits de `agent.md`
5. **Push**: `git push origin <branch>`
